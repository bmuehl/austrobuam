## Ausrichtung der Website

Diese Website präsentiert die Original Austrobuam, eine Gruppe von Musikern aus Wiener Neustadt. Sie informiert über die Band, ihre Mitglieder und Auftritte, zeigt Bilder und bietet eine Kontaktmöglichkeit für Konzert- und Buchungsanfragen.
